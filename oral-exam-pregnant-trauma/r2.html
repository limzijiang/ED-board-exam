急診專科口試 — 孕婦創傷情境模擬（r2）

26 歲懷孕 28 週副駕駛，車禍後下腹痛｜一般級急救責任醫院（無婦產科）
🎧
逐字稿
摘要 / 評分重點
考官 / 病人角色 考生 r2 學長講評 段落
⏱ 00:00 — 一、病史詢問
00:00
考生
我們先詢問病人的病史——問她是怎麼發生的？（汽車與汽車車禍，副駕駛）當下有沒有失去意識？（沒有）有繫安全帶。本身有沒有慢性病史、有沒有吃抗凝血的藥物？然後問她哪裡不舒服——下腹痛？有沒有呼吸喘、頭痛頭暈？（都沒有，就下腹痛）
⏱ 01:20 — 二、身體檢查
01:20
考生
做一些身體檢查——按壓腹部看哪裡疼痛、有沒有 rebound pain、muscle guarding。然後做簡單的神經學：coordination、finger-nose。
01:50
考官
下腹、腰痛，finger-nose 都正常。GCS 是 E3V5M6，瞳孔 3/3 有 light reflex。
⏱ 02:10 — 三、檢驗 + POCUS
02:10
考生
先安排抽血：CBC/DC、三管、Gas、D-dimer。然後安排 echo（E-FAST），看有沒有腹腔內出血、有沒有 hemoperitoneum 的情況。治療基本先上 IV。
02:55
考生
檢查結果——看起來體內有一些 ascites，懷疑可能是脹氣/臟器損傷，有可能是 spleen 或 liver，也有可能是子宮出血，甚至子宮破裂或胎盤剝離都可能。因為出血是比較隱匿的問題，可能需要輸血，也會驗血型，並照會婦產科醫師安排後續的陰道超音波。
⏱ 03:45 — 四、向病人解釋 + 治療
03:45
考生
跟病人解釋：我們掃超音波看到肚子裡有一些積液，有可能是出血。會先給她輸液/輸血，找婦產科醫師做後續檢查。假如真的有子宮破裂或胎盤剝離，是有可能需要進一步手術的。
⏱ 04:55 — 五、第二題：突發大出血 → 急救
04:55
考官
她生命徵象還算不會太差——假如突然大出血，直接被推入急救室。
05:10
考生
突然大出血表示出血問題變嚴重了。可能要緊急做檢查，比如 CTA 看是不是有動脈出血。也要跟病人解釋處置的必要性、對胎兒的影響。輸血一定要，可能給止血藥物——全靜脈、TXA 之類避免繼續出血。再根據後續檢查，找 code trauma team 評估，是不是有內臟臟器出血或血管出血的可能。
⏱ 06:11 — 六、臨床臆斷（第四題）
06:20
考生
可能臆斷第一個就是子宮破裂（uterine rupture）——因為 echo 上子宮旁邊有一個 hypoechoic lesion（應該是 ascites），而且子宮體本身看起來有缺損，所以可能是子宮體破裂，這是最可能的臆斷。當然可能合併其他臟器損傷（像 spleen 破掉）。但我還是以子宮體破裂為最可能。
⏱ 07:20 — 七、心跳停止 → CPR
07:21
考官
她現在沒有 pulse。
07:30
考生
沒有 pulse → CPR，上 monitor。Monitor 顯示 PEA → 繼續 CPR。扣搭在一起、給予高級呼吸道（插管）、給予高品質 CPR、給予藥物——每 3 分鐘打一次 epinephrine，分析心律看有沒有需要電擊的節律。輸血，然後掃 echo，找 5H5T 看有沒有其他導致的問題。
⏱ 08:30 — 八、向家屬解釋病情
08:30
考生
跟家屬說：我們懷疑她有子宮體破裂，有可能導致腹內大出血。會找 trauma team 及婦產科醫師來看要不要做緊急手術。她現在可能是失血過多導致心跳停止，我們正在緊急急救。現在是緊急狀況，胎兒有可能保不住，我們會以優先拯救媽媽為主。
📣 09:40 — 學長講評（Debrief，剩約 5 分鐘）
09:45
學長
差不多這樣，還有 5 分 14 秒，時間掌控還蠻不錯的。

病史詢問可以再補：病人下腹痛要問痛的性質（一陣痛？鈍痛？）、痛多久、怎麼發生（車禍）、什麼情況緩解或加劇、除了下腹痛有沒有其他症狀。還要問車禍當下的速度——高速撞擊還是停等被撞、當下有沒有 consciousness change。
11:00
學長
身體檢查——除了按壓腹部，還要看有沒有其他地方瘀斑、聽診呼吸音、檢查頭部外傷、肢體明顯損傷變形。神經學 N1 看 muscle power、能不能 follow、視力有無缺損、有沒有 diplopia。
12:00
學長
處置主要就是輸血、輸液。動向的話——找後線外科、trauma、婦產科。急救時 IV / O₂ / monitor、CPR、epinephrine、5H5T 要找，還要再抽一次血看有沒有 electrolyte imbalance、看 gas 有沒有變很酸、看陰道有無大出血。必要時插管。跟病人講解後續除了手術還要住加護病房——如果 CPR 救回來，可能還要做更多詳細檢查。

🩺 情境設定

26 歲懷孕 28 週副駕駛，車禍後下腹痛｜一般級急救責任醫院（無婦產科）。

✅ 表現亮點

  • 結構清楚、時間掌控好（學長評「還蠻不錯的」，剩 5 分鐘）
  • PE 有做神經學（rebound、guarding、finger-nose、GCS、瞳孔）
  • POCUS / E-FAST 有掃，判讀積液 → 想到子宮破裂/胎盤剝離/臟器損傷
  • 有提 TXA 止血藥、code trauma、CTA 找動脈出血
  • CPR：PEA → epinephrine q3min + 5H5T + echo；家屬解釋清楚（優先救媽媽）

⚠️ 失分 / 方向差異

  • 主診斷選 uterine rupture（評分單僅 2 分）而非標準答案 placental abruption（3 分）
  • 完全沒提 HELLP（沒問產檢血壓、沒判讀 schistocyte/肝指數）、沒提 DIC
  • 病史缺：痛的性質/時長、撞擊速度、G/P、AMPLE 不完整（學長點出）
  • CPR 沒提子宮左推 / perimortem C-section（此題兩位標準要點）
  • 治療缺：Rho(D) Ig / Vit K / 破傷風、宮底高度、ISBAR 交班
