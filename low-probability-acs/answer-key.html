■ 低風險急性冠心症（Low-Probability ACS）重點整理

1. 何謂「低風險 ACS」

  • 到急診胸痛病人中，約 15–25% 最終診斷為 ACS
  • 急診初步評估後判斷 30 天 ACS 風險 < 1%者，即視為「低風險」
  • 主要目標：安全出院並避免不必要的住院、影像、侵入性檢查

2. ACS 之高風險特徵 vs 非典型表現

高風險特徵（提高 ACS 可能性）非典型 ACS 高風險族群
  • 胸部受壓迫感（pressure，LR+ 1.3）
  • 與既往心因性疼痛相似或更劇（LR+ 1.8）
  • 合併噁心嘔吐（LR+ 1.9）
  • 合併冒冷汗（diaphoresis）（LR+ 2.0）
  • 放射至雙臂、肩、下顎
  • 運動誘發、休息後緩解
  • Nitroglycerin 緩解（特異性低）
  • 女性（約 37.5% 無胸痛）
  • 糖尿病（自律神經病變）
  • 老年人
  • CKD／透析病人
  • 非典型表現：單純呼吸喘、虛弱、噁心、上腹痛、心悸、昏厥
⚠ 注意：噁心嘔吐／冒冷汗不是低風險特徵，反而是 ACS 的高風險特徵。

3. HEAR Score（Tintinalli's CH 51 Table 51-1）

項目2 分1 分0 分
History（病史） 高度可疑中度可疑輕度可疑
ECG 明顯 ST 段壓低非特異性 repolarization 異常正常
Age（年齡） > 6545–65≤ 45
Risk factors* ≥ 3 項 或 已知 CAD/PAD/CVD1–2 項無
* Risk factors: 現用降糖藥的糖尿病、現在或近 90 天內抽菸、診斷或治療中的高血壓、高膽固醇、CAD 家族史、肥胖。
判讀：總分 0–3 = Low risk；≥ 4 = High risk。
HEART score = HEAR + Troponin（多一項，每項 0–2 分），是完整版；HEAR 是省略 troponin 的縮短版。

4. HEART Pathway（急診出院流程）

步驟內容
1. 評估EKG + 計算 HEAR score（在抽 troponin 前）
2. Troponin 採檢 使用 高敏感性 troponin（hs-troponin）：
  • 0 小時 + 3 小時（或符合條件可單次 0 小時就出院）
  • 若用傳統 troponin → 0 小時 + 3 小時 + 6 小時
3. 判讀 HEAR ≤ 3 + 兩次 troponin 陰性 → 30 天 ACS 風險 < 1%，可安全出院
HEAR ≤ 3 + 0/3h 高敏感 troponin 陰性 → 亦可考慮出院
HEAR ≥ 4 或 troponin 陽性 → 住院、進一步檢查
4. 出院安排 72 小時內門診追蹤、再評估；若已知 CAD 或不穩定，不適用此 pathway 直接出院
⚠ HEART pathway 不適用的病人：
  • STEMI 或新發 EKG 缺血變化
  • 已知 CAD 病史 + 高度疑似新發 ACS
  • 嚴重結構性心臟病（如重度 AS）
  • 血液動力學不穩定

5. 急診其他評估工具的角色

工具用途 / 限制
心電圖（EKG） 所有胸痛病人 10 分鐘內必做；正常 EKG 不能排除 ACS（敏感度 ~50%）
Troponin 診斷 MI 之核心；hs-troponin 敏感度更高、可縮短診斷時間； 但 troponin↑不等同於 ACS（見下表）
心臟超音波（echo） 看 wall motion abnormality、EF、結構問題； 非急診排除 MI 的工具，不能因 echo 正常就排除 ACS
近期 stress test 陰性 stress test 不代表將來不會 ACS； 研究顯示近期 stress test 陰性者 6 個月 ACS 發生率仍可達 14%
運動心電圖（exercise stress test） 低風險病人出院後門診追蹤之選項之一； 相對禁忌症包括重度 AS、左主幹狹窄、未控制高血壓、活動性 ACS
Coronary CTA 對解剖性病灶敏感度高；適用於中低風險病人； CAC（冠脈鈣化）= 0 預測 ACS 機率極低

6. Troponin 升高但非 ACS 的情況

  • 心因性非缺血性：HF（急慢性）、HCM、aortic dissection、心臟挫傷、心臟手術／pacing／ablation、tachy/bradyarrhythmia、心肌炎、心包炎、Takotsubo
  • 肺血管：肺栓塞（大塊 PE）、肺動脈高壓
  • 系統性：敗血症、嚴重燒傷、極限運動
  • 腎臟：CKD／ESRD（chronic troponin 升高）
  • 神經：急性中風、SAH（neurogenic stress cardiomyopathy）
  • 毒物：cocaine、化療藥物、CO 中毒

7. 胸痛常見鑑別（非 ACS）

疾病關鍵線索
Aortic dissection劇烈撕裂痛 + 雙臂血壓差 > 20 mmHg、放射至背、X 光縱膈增寬
肺栓塞 PE胸痛 + 呼吸喘 + 心搏快 + 下肢腫；high-risk 可考慮 D-dimer 或 CTA
Boerhaave's syndrome 劇烈嘔吐後胸痛；常合併酗酒、進食過多； 食道遠端左側破裂；可有縱膈氣腫；診斷：吞水溶性顯影劑或 CT； 治療：抗生素 + 立即手術
Cocaine-induced MI 年輕病人胸痛 + cocaine 史；約 6% 的 cocaine 後胸痛者為 AMI； 避免 β-blocker（unopposed α 收縮）；給 BZD、aspirin、NTG、CCB； 近 20 年使用者平均年齡升至 50 歲
急性心包炎銳痛、躺平加重、坐起緩解；摩擦音；廣泛 ST 凹形上升 + PR 壓低
GERD燒灼感、餐後加重；診斷之外應先排除嚴重病因
第 1 題 ［111 Q25］　答案：D
42 歲男性胸悶 + 嘔吐 + 冒冷汗，NTG 未緩解，EKG 無明顯 ST-T 變化，何者較適當？
  • （Ａ）噁心嘔吐等腸胃道症狀屬低風險特徵。
  • （Ｂ）6 個月內正常 stress test → MI 可能性較低。
  • （Ｃ）Echo 無 wall motion abnormality → 可排除 MI。
  • （Ｄ）症狀改善 + 3hr Troponin 無異常 → 可門診追蹤。

詳解

(A) 錯：噁心嘔吐／冒冷汗是高風險特徵 （nausea LR+ 1.9、diaphoresis LR+ 2.0），不是低風險。
(B) 錯：近期 stress test 陰性不代表不會 ACS。 6 個月 ACS 發生率可達 14%。
(C) 錯：MI 不靠 echo 診斷或排除；wall motion abnormality 敏感度有限。
(D) 正確：使用 HEAR score 評估，本病人：
  • History（胸悶 + 噁心 + 冒冷汗 + NTG 未緩解）= 高度可疑 = 2 分
  • EKG 正常 = 0 分
  • Age 42 ≤ 45 = 0 分
  • Risk factors 無 = 0 分
  • HEAR = 2 → Low risk
Low risk + 2 次 troponin 陰性（或 hs-troponin 0/3h 陰性）→ 可安全出院。 3 小時後追蹤 troponin 為 HEART pathway 的標準時間點。
Ref: Tintinalli's 9e CH 51 Low-Probability ACS, p. 357–359, Table 51-1
第 2 題 ［111 Q192］　答案：C
有關急性胸痛，下列何者較適當？
  • （Ａ）18 歲男性 cocaine 胸痛 2 天，較不可能 ACS。
  • （Ｂ）64 歲糖尿病女性上腹痛 + 雙臂痠痛，較不可能心臟。
  • （Ｃ）70 歲肝硬化酗酒男性劇烈嘔吐後胸痛 → 需考慮 Boerhaave's syndrome。
  • （Ｄ）急性中風病人心肌指數不會上升。

詳解

(A) 錯：Cocaine 後胸痛者約 6% 為 AMI， 雖好發於年輕人，不能因為年輕就排除。Tintinalli's 指出 cocaine 相關 MI 平均年齡已由 38 歲上升至 50 歲。
(B) 錯：女性、糖尿病、老年人為非典型 ACS 高風險族群； 上腹痛 + 雙臂痠痛正是典型的非典型 ACS 表現，不能排除。 高達 37.5% 女性 MI 病人無胸痛。
(C) 正確：Boerhaave's syndrome 為食道全層穿孔， 機轉為突發劇烈嘔吐導致食道內壓快速上升（也可由咳嗽、用力、抽搐、生產引起）。 酗酒常為前置因素。 穿孔多在遠端食道左側，可有縱膈氣腫。 診斷：水溶性顯影劑吞嚥造影或 CT；治療：廣效抗生素 + 立即手術。
(D) 錯：急性中風（特別是 SAH）可造成 neurogenic stress cardiomyopathy（神經源性心肌病變、Takotsubo）， troponin 可上升。其他造成 troponin 升高但非 ACS 的情況包括 HF、PE、HCM、敗血症、CKD、心肌炎等。
Ref: Tintinalli's 9e CH 48（Troponin in non-ACS）、CH 51 Low-Probability ACS、CH 70（Boerhaave's），p. 331, 336, 352, 502
第 3 題 ［113 Q137］　答案：D
根據低危冠心症風險評估的 HEART pathway，急診胸悶病人處置下列何者較適當？
  • （Ａ）已知 CAD 病史，HEAR 1 分，單次 Troponin 陰性可出院。
  • （Ｂ）嚴重 AS 病人，多次 Troponin 陰性 + 症狀緩解，72 hr 內安排運動心電圖。
  • （Ｃ）儘早安排 echo，若正常可排除 ACS。
  • （Ｄ）左主幹支狹窄是運動心電圖的相對禁忌症。

詳解

(A) 錯：HEART pathway 不適用於已知 CAD 病人（這類病人本身高風險）。 此外即使要採用 pathway，也應該抽 2 次 troponin（傳統 0/3/6h，或 hs-troponin 0/3h）而非單次。
(B) 錯：重度 AS 是運動心電圖的禁忌症（誘發暈厥、惡性心律不整、猝死風險）。 此病人不應安排運動心電圖追蹤；應改為藥物壓力測試（dobutamine echo / nuclear stress test）或 CTA。
(C) 錯：Echo 正常不能排除 ACS（細微 wall motion abnormality 可能漏看， 也可能在症狀緩解後恢復）。Echo 主要用於評估結構性問題。
(D) 正確：運動心電圖（exercise stress test）之 相對禁忌症包括：
  • Left main coronary artery 已知狹窄
  • 中重度 AS（severe AS 為絕對禁忌）
  • 未控制的高血壓（SBP > 200、DBP > 110）
  • 急性心律不整／嚴重 bradyarrhythmia
  • 活動性 ACS / 不穩定心絞痛
  • 急性心肌炎、心包炎
  • 嚴重肺高壓
  • 無法配合運動（替代為藥物壓力測試）
Ref: Tintinalli's 9e CH 51；ACC/AHA Exercise Stress Test Guidelines
